# frame-jp-keyboard 設計書（v0.1 草案）

Steam Frame 本体の中で使う日本語キーボード。スマホのキーボードのような**フリック入力**と**英語⇔日本語のワンタッチ切り替え**ができるようにする。

## 1. 前提（2026-09-26 に実機で確認済み）

| 項目 | 内容 |
|---|---|
| 本体 | SteamOS 0.4.1 ベータ、SteamVR 2.18.1、Steam UI changelist 11041156 |
| 差し込み口 | Steam が `-cef-enable-debugging` で起動し、`127.0.0.1:8080` に Chrome DevTools Protocol（CDP）がある。本体の中からしか繋がらない |
| キーボード本体 | `SharedJSContext` の中の React コンポーネント。VR では `SteamVR - Keyboard`（`vrOverlayKey=valve.steam.gamepadui.keyboard`）のポップアップにポータルで描画している |
| 見つけ方 | `webpackChunksteamui.push` でモジュール表を取得。設定ストアは `GetKeyboardLayoutSettings` を持つモジュールを検索して見つける。`SteamUIStore.WindowStore.SteamUIWindows[i].VirtualKeyboardManager` が存在する |
| 日本語変換 | `window.IBus`（ネイティブの IBus バインディング）経由で ibus-anthy を使う。`xkb:us::eng` と `anthy` が入っている |
| 文字の送り先 | VR では `SteamClient.OpenVR.Keyboard.SendText`、それ以外は `SteamClient.Input.ControllerKeyboardSendText`。どちらも `VirtualKeyboardManager` が振り分ける |
| 実行環境 | Python 3.12 と aiohttp が入っている（node は無い） |

### 「英語に戻れない」件の原因

実機の設定を読むと `{currentLayout: 12, selectedLayouts: [12]}` で、**有効なキーボードが日本語だけになっていた**。地球儀キーは有効なキーボードの中しか回らないので、英語に戻れない。設定 → キーボード → 有効なキーボードに英語（QWERTY）を足せば、自作を待たずに直る（2026-09-26 に実機で確認）。

このほかにも、純正側には不具合の候補が 2 つある（どちらも推測で、実機では未確認）。
- 設定を変えても、表示中のキーボードに反映されない。
- 素早く切り替えると IBus のエンジン指定が後から上書きされる。

## 2. 方式

```
[Frame 本体]
  systemd --user: frame-jp-keyboard.service
    └─ injector（Python + aiohttp）
         ├─ CDP で SharedJSContext を見張る（Steam の再起動・リロードのたびに差し直す）
         └─ Runtime.evaluate で bundle.js を差し込む
  SharedJSContext
    └─ bundle.js（自作。ES modules を esbuild で 1 ファイルにまとめる）
         ├─ 純正キーボードの popup（valve.steam.gamepadui.keyboard）に自作 UI を重ねる
         ├─ 変換: IBus の input context（anthy）
         └─ 出力: VirtualKeyboardManager の既存の経路に渡す
```

- **Steam のファイルは一切書き換えない**。実行時に差し込むだけなので、サービスを止めて Steam を再起動すれば純正に戻る。
- 要になる部分が見つからないとき（Steam の更新で中身が変わったなど）は**何もしない**。純正キーボードがそのまま使える状態を保つ。
- 探すときは、ミニファイされない名前だけを手がかりにする。
  - メソッド名（`GetKeyboardLayoutSettings`、`HandleVirtualKeyDown` など）
  - 文字列（`"xkb:us::eng"`）
  - DOM（`data-key`、`Layout_<name>`）
- 差し込み役のサービスはユーザー権限で動かす。置き場所は frameeyeosc と同じ `~/.local` と `~/.config`（sudo 不要）。

## 3. 画面と操作

### 日本語（12 キーのフリック）

```
┌─────┬─────┬─────┬─────┬─────┐
│  ↶  │  あ  │  か  │  さ  │  ⌫  │
├─────┼─────┼─────┼─────┼─────┤
│  ←  │  た  │  な  │  は  │  →  │
├─────┼─────┼─────┼─────┼─────┤
│ ☺記 │  ま  │  や  │  ら  │ 空白 │
├─────┼─────┼─────┼─────┼─────┤
│ あA  │゛゜小│  わ  │、。?!│  ⏎  │
└─────┴─────┴─────┴─────┴─────┘
 ↑ 上に変換候補のバー（横スクロール）
```

- **フリック**: キーの上でトリガーを引き、そのまま上下左右にレーザーを振って離すと入力する。
  - 左＝い段、上＝う段、右＝え段、下＝お段（スマホのフリック入力で一般的な向き）。
  - 引いた瞬間に十字のガイドを出す。
- **トグル入力**: 同じキーを続けて押すと「あ→い→う…」と進む。オン／オフは設定で選べる。
- **判定の基準**: 振った距離ではなく、キーの中心から見た**角度（レーザーの向き）**で判定する。振った量のしきい値は設定で変えられる。
- **゛゜小**: 直前の文字を濁点・半濁点・小文字の順に切り替える。
- **空白キー**: 変換中は「変換」になり、次の候補に進む。
- **⏎**: 変換中は確定、それ以外は改行または送信。

### 英語（QWERTY）

純正と同じ QWERTY だけど、見た目は日本語側とそろえる。左下の **あA キーをワンタッチ**すると日本語に戻る。

### 切り替え

- **あA キー 1 回**で英語と日本語が入れ替わる。純正の「有効なキーボード」の設定とは別に、自作キーボードの中だけで切り替える。
- 前回使ったモードを覚えておく。

## 4. 変換

- 最初は **ibus-anthy** を使う。フリックで作ったひらがなをローマ字のキー入力に直して、自作の IBus の input context に送る。
  - 変換中の文字と候補は、IBus から届く合図（preedit、lookup table）を受け取って、自作の候補バーに出す。
  - Steam 純正の `IBus` バインディングがそのまま使えるかは、M3 で確かめる。
- Mozc（オープンソースの変換エンジン）は Frame に入っていない。aarch64 でビルドしてホームフォルダに置けるかは、あとで調べる（候補: fcitx5-mozc のエンジン部分、または mozc_server 単体）。
- **予測変換**（打ちかけで候補を出す）は anthy では弱いので、Mozc を入れるかどうかの判断材料にする。

## 5. 出力

- 確定した文字は `VirtualKeyboardManager` の既存の経路に渡す。これで Steam UI の入力欄にも、VR アプリにも純正と同じように届く。
- ⌫・⏎・矢印も、純正と同じ特殊コード（`"\b"`、`"\n"` など）で送る。

## 6. マイルストーン

| # | 内容 | 終わったと言える条件 |
|---|---|---|
| M0 | 英語に戻れない件を設定で直す | 地球儀キーで英日が回る（ユーザーが操作して確認） |
| M1 | 差し込み役のサービスと「目印を出すだけ」の bundle | Steam 再起動後も自動で差し直され、ログに出る |
| M2 | **VR のレーザーでドラッグが取れるかの検証** | キーボードの popup で pointerdown → move → up の座標が取れる。取れないならフリックの方式を考え直す |
| M3 | フリックでひらがなを直接確定（変換なし） | Steam の検索欄に「あいう」が入る |
| M4 | anthy 変換と候補バー | 「かんじ」→「漢字」が確定できる |
| M5 | QWERTY、あA 切り替え、゛゜小、記号、トグル入力、見た目 | ユーザーが実際に使って OK を出す |
| M6 | install.sh と README | まっさらな状態から入れて、外して、また入れられる |

M2 が一番の不確定要素なので、M1 とあわせて最初に確かめる。
